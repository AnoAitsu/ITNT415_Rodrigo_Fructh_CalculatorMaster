## Project Description
A menu-driven Python calculator built using Git and GitHub feature branching.
Each arithmetic operation (addition, subtraction, multiplication, division)
was developed on its own branch and merged into main via a reviewed Pull Request.

## Branch Structure

- subtraction_Rodrigo
- multiplication_Rodrigo
- division_Rodrigo

## Program Features
- Menu-driven interface
- Input validation for non-numeric entries
- Division-by-zero handling
- Continuous execution until the user chooses Exit
